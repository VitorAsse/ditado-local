# Segurança

## Relatar uma vulnerabilidade

Não publique detalhes exploráveis em uma issue aberta.

Use o recurso privado de relato de vulnerabilidades do GitHub quando ele estiver
disponível no repositório. Para problemas sem conteúdo sensível, abra uma issue comum.

Inclua a versão afetada, o caminho reproduzível, o impacto e uma sugestão de correção
quando possível.

## Limites de confiança

- O aplicativo é destinado ao uso local em uma conta do Windows.
- Regras, skills e correções são tratadas como configuração confiável do usuário local.
- Textos selecionados e conteúdo da área de transferência podem conter dados sensíveis.
- O endpoint padrão do Ollama aceita apenas conexões locais.
- Alterar `DITADO_OLLAMA_URL` pode enviar texto para outro computador ou serviço.
